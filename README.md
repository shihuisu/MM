# TRACE

**Live experience:** https://shihuisu.github.io/MM/

TRACE is an interactive speculative fiction about memory, learning and the cost of outsourced cognition. Set in 2047, it follows a student living under a mandatory neuro-learning system whose promise of equality has hardened into uniformity.

## Experience

The project is structured as an eight-chapter digital novella. A restrained black-and-white visual system, ambient sound, moving-image material and small narrative choices turn the browser into a speculative archive rather than a conventional scrolling website.

The reader can:

- move through the story with on-screen controls, keyboard arrows or horizontal touch gestures;
- open memory fragments and respond to narrative prompts;
- encounter a simulated cognitive subscription interface;
- watch an embedded moving-image sequence within the story.

## Project information

- **Project type:** Individual project
- **Year:** 2025
- **Role:** Concept, research, narrative writing, interaction design, visual direction and front-end development
- **Format:** Interactive web narrative with image, sound and video
- **Built with:** HTML, CSS and JavaScript

## Themes

- outsourced memory and cognition;
- technological access versus social conformity;
- subscription-based learning;
- forgetting as a form of human agency;
- the ethics of implantable neurotechnology.
